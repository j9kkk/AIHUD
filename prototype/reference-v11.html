V11-03 · 转场与交互架构：极速 280ms 弹性滑入 + 3 种极简返回途径
转场动效PushNavigation手势返回
macOS Push Navigation 转场架构
• 点击交互：在一级卡片点击任意账号（例如『工作主力』）；
• 物理滑入：一级网格向左轻微平移 (X: -40px) 并淡出，二级详情页从右侧平滑滑入 (X: 0)；
• 动画曲线：cubic-bezier(0.16, 1, 0.3, 1)（Apple 原厂轻巧减速曲线），耗时 280ms；
• 返回方式：
  1. 点击顶部 ‹ 全部账号
  2. 键盘直接按 Esc 键
  3. 触控板从左边缘向右单指轻扫 (Edge Swipe Back)；
• 尺寸一致：面板宽高完全保持 412px，视窗绝不抖动变形。
✓ 完美兼顾：一级界面极致防窥与紧凑，二级界面极致详尽与硬核。
交互与设计说明：为什么这是最佳体验组合？
• 传统 Tooltip 悬停浮层容易遮挡下方卡片，且面积狭小无法展示调用趋势；
• 弹窗 Modal 会破坏 HUD 沉浸感；
• 全区域滑入（Push Navigation） 是 macOS / iOS 最地道的原生导航范式，让一个小小 412px 的 HUD 面板具备了专业级开发工具的纵深。
