# Apple 设计规范要点（所有方向必须遵守）

来源：Apple 人机界面指南（中文版）https://developer.apple.com/cn/design/human-interface-guidelines/
原文已抓取到同目录 `HIG/*.md`，共 17 页。设计前**至少读完**以下页面：
`HIG/the-menu-bar.md`、`HIG/popovers.md`、`HIG/materials.md`、`HIG/layout.md`、`HIG/typography.md`、`HIG/color.md`、`HIG/gauges.md`、`HIG/dark-mode.md`、`HIG/accessibility.md`。
有疑问时以原文为准。

## 从 HIG 落到本项目的规则（逐条可验收）

| # | 来源页 | 规则 | 怎么验 |
|---|---|---|---|
| H1 | 菜单栏 | 菜单栏附加项点开后，内容出现在图标正下方；附加项图标用模板图（单色），只在告警时用颜色 | 面板顶边贴菜单栏下 6px，右边缘对齐图标 |
| H2 | 弹出窗口 | 弹出内容只放与当前任务相关的信息；不要在弹出窗口里再弹窗口；内容尺寸贴合，不留大块空白 | 面板高度随内容；无空白带 |
| H3 | 材质 | 内容层用标准材质（半透明 + 模糊），文字用系统活力色（label / secondaryLabel），不要在材质上加不透明底 | 背景能透出桌面纹理 |
| H4 | 布局 | 用对齐、间距、分组建立层级；相关内容靠近、无关内容分开；对齐到统一网格；重要信息放在前面和左上 | 列/行对齐量出来一致；4pt 网格 |
| H5 | 排版 | 用 macOS 内建文本样式（大标题 26、标题1 22、标题2 17、标题3 15、标题 13 半粗、正文 13、标注 12、副标题 11、脚注 10）；macOS 最小 10pt；用字重与颜色区分层级，**字重不要太多** | 字号 ∈ {17,15,13,12,11,10}；字重 ∈ {400,600} |
| H6 | 颜色 | 用系统颜色和语义色，**同一种颜色只表达一种含义**；不要只靠颜色传达信息；深浅两种外观都要有足够对比 | 正常绿 / 低红 / 需操作橙 / 交互蓝；异常态有形状或文字 |
| H7 | 仪表 | 仪表（Gauge）表示一个范围内的值；容量样式填充表示当前值；可在关键阈值改变填充颜色；用标签说明数值含义 | 环/条有轨道；低于 20% 填充变红；旁边有数值和窗口名 |
| H8 | 深色模式 | 不要硬编码颜色，深浅各一套语义值；深色下降低大面积纯白 | 两套截图对比度都合格 |
| H9 | SF Symbols | 图标风格与系统一致（线条粗细与文字字重匹配），不要自造复杂图形 | 刷新/外链等图标用简洁线性形状 |
| H10 | 无障碍 | 控件最小 28×28（推荐），文字对比度正文 ≥ 4.5:1；不只靠颜色 | 量命中区；算对比度 |
| H11 | 动态效果 | 动画要有目的、简短；支持“减弱动态效果” | 有 prefers-reduced-motion 处理 |
| H12 | 反馈 | 状态变化就地反馈（刷新中、已更新），不打断用户 | 刷新时保留旧数值，只改状态文字 |

**禁止**：网页 SaaS 卡片风、渐变装饰、emoji、仿冒品牌 Logo、胶囊大按钮堆叠、左侧色条、iOS 风格的大号实心按钮成排出现。
