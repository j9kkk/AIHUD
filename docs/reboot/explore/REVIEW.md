## 规范复审：p11 / p12（字体层级、分割线、透明度、按钮位置）

| 透明度 | label 1.0 / 0.88 · secondary 0.72 / 0.65 · tertiary 0.55 / 0.48（仅装饰，不用于正文） |
| 对比度 | secondary 在合成底色上：深色 8.7:1、浅色 6.6:1（正文要求 4.5，小字 7 已达到或接近） |

### 与 Apple 的有意偏差（写明理由）
- **次要文字比系统语义色更亮**：Apple secondaryLabel 浅色约 0.50、深色约 0.55；本项目用 0.65 / 0.72。原因是面板叠在高对比桌面上时，0.50 实测约 4.0:1，低于 HIG 对小字的 4.5:1。这里选择可读性优先。
- **模块底色用填充而非活力材质**：面板本身是毛玻璃，模块再叠 6–10% 填充，等价于 macOS 的 quaternarySystemFill。
