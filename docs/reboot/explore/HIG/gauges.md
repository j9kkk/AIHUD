# Apple HIG（中文）· gauges
来源：https://developer.apple.com/cn/design/human-interface-guidelines/gauges

仪表
仪表显示某个值范围内的特定数值。

除了指示范围内的当前值，仪表还可提供关于范围本身的更多上下文。例如，温度仪表可使用文本来标识范围内的最高温和最低温，并显示色谱来从视觉上凸显变动的值。

剖析

仪表使用圆形或线性路径来呈现值范围，并将当前值映射到路径上的特定点。标准仪表会显示用于指示当前值位置的指示符；使用容量样式的仪表会填充路径并在值位置处停止。

使用标准和容量样式的圆形及线性仪表还具有看起来类似于 watchOS 复杂功能的变体。此变体（称为附属功能）非常适用于 iOS 锁屏小组件以及想要重现复杂功能外观的任何位置。

注

除了仪表，macOS 还支持级别指示符，其中部分具有类似于仪表的视觉样式。有关指南，请参阅 macOS。

最佳实践

编写描述当前值以及范围两端点的简洁标签。虽然并非所有仪表样式都会显示全部标签，但“旁白”会朗读可见标签以帮助用户不看屏幕即可理解仪表。

考虑使用渐变色填充路径，以帮助传达仪表的用途。例如，温度仪表可能使用从红色到蓝色的颜色范围，来呈现从热到冷的温度范围。

平台考量因素

无针对 iOS、iPadOS、visionOS 或 watchOS 的额外考量因素。在 Apple tvOS 中不受支持。

macOS

除了支持仪表，macOS 还定义了显示范围内特定数值的级别指示符。你可以将级别指示符配置为指示容量、评分或（少数情况下）相关性。

容量样式可描述离散或连续值。

连续。半透明的水平轨道，使用实心条填充以表示当前值。

离散。独立、等大的矩形分段组成的水平行。分段的数量符合总容量，并且填满色（不会部分填色）以指示当前值。

考虑为较大范围使用连续样式。较大的值范围可能会使离散容量指示符的分段变得太小而无法使用。

考虑更改填充色以告知用户范围中的重要部分。两种容量指示符样式的填充色都默认为绿色。如果在你的 App 中适用，你可以在当前值达到某个级别（如非常低、非常高或刚好超过中间值）时更改填充色。你可以更改整个指示符的填充色，还可使用多级状态来在单个指示符中显示一系列不同颜色（如下所示）。

多级外观

有关使用评分样式来帮助用户评价内容的指南，请参阅评分指示符。

相关性样式可使用渐变的横条来传达相关性，但其较少使用。例如，相关性指示符可能出现在搜索结果列表中，以在排序或对比多个项目时帮助用户直观看到结果的相关程度。
