# p11 / p12 实现规格（MVP A / MVP B 共用数据层）

> 原型：`p11.html`（一级模块 + 二级时间轴）、`p12.html`（列表 / 圆环双视图 + 详情）。
> 本文件把原型翻译成可实现的数字与状态，供并行开发的两个 MVP 对照。

## 2. 数据层（两个 MVP 共用）

- 钥匙串服务名：`app.aihud.slice`（MVP 复用切片已授权凭据，正式版改名）
- 账号元数据：`~/Library/Application Support/AIHUDSlice/accounts.json`（不含凭据）
- 授权：Claude / Codex 走本机回调（54545 / 1455）；WorkBuddy 走登录状态轮询
- 取数：三渠道并发，单账号失败不影响其他
- 状态映射：
  - 200 + 解析成功 → `ok([Window])`
  - 401/403/400 → `reauth`
  - 429 → `limited`
  - 其他（含超时）→ `unreadable`
- 窗口数据：`label`（「5 小时」「本周」「积分」）、`remaining`（0–1）、`valueText`（「52%」或「1,579 / 13,326」）、`resetText`（「今天 02:30」或「11 月 9 日 到期」）

## 3. MVP A（p11）：模块 → 时间轴

### 一级
- 通栏大模块：最紧张账号（`min(remaining)` 最小者）；高 = 12 上下 + 18 标题 + 8 + 22 数值 + 8 + 6 条 + 6 + 14 附注 ≈ 98pt
- 两个并排小模块：其余账号按渠道顺序；宽 = (352 − 24 − 8) / 2 = 160pt
- 底部分组线 + 两行命令（28pt 高）：「添加账号…」「AI HUD 设置…」
- 点模块任意位置 → 推入二级

### 二级（时间轴）
- 头部：返回 28×28 + 账号名 13/600 + 套餐 10/400 + 刷新 28×28
- 每个窗口一行：左列 84pt（倒计时 13/600 + 时刻 11/400）、轨道 12pt（中性节点 + 竖线 + 首尾淡尾线）、右侧（窗口名 13/400 + 数值 17/600 + 条 6pt + 说明 11/400）
- 积分类账号（无重置）：不出现在时间轴，单独一行「积分 1,579 / 13,326 · 11月9日 到期」
- 失效账号：不画轨道，一条告警行 + 「重新授权…」按钮（右下）
- 底部：分组线 + 「打开用量页面…」+「移除此账号…」

### MVP A 高度预算
一级 ≈ 353pt；二级（2 窗口）≈ 271pt；二级（失效）≈ 246pt

## 4. MVP B（p12）：双视图 + 详情

### 头部
- 标题 13/600 + 「剩余 · 00:04 更新」11/400
- 右侧：视图分段控件（2 个图标，容器 28 高、每段 30×28，选中态 22 高滑块）+ 刷新 28×28

### 视图 A 列表
- 每账号一行 56pt：左（名字 13/600 + 套餐 10/400；第二行 11/400 次要色）、右（数值 13/600 + 24pt 圆环）
- 行间 1 物理像素分割线，内缩 12pt
- 失效账号：虚线环 + 感叹号，第二行为橙色「登录已失效 · 需重新授权」，无数值

### 视图 B 圆环
- 4 列网格，格子 78×92：环 52pt（线宽 5）、环内 15/600 圆体、名称 11/400、附注 10/400
- 失效账号：虚线环 + 告警符号

### 详情（两种视图共用）
- 头部：返回 + 账号名 + 套餐 + 刷新
- 每个窗口一行：28pt 小圆环 + 窗口名 13/400 + 重置时间 11/400 + 右侧 17/600 数值；行间 1 物理像素线内缩 25pt
- 失效账号详情：告警块（图示 + 「登录已失效」+ 说明）+ 一行「无数据 / 上次成功读取」+ 右下「重新授权…」
- 底部：「打开用量页面…」+「移除此账号…」

### MVP B 高度预算
列表 ≈ 351pt；圆环 ≈ 224pt；详情（2 窗口）≈ 234pt；异常详情 ≈ 272pt

## 5. 原型中不可实现 / 需要修改的部分（请审核）

| # | 原型里的写法 | 问题 | 建议 |
|---|---|---|---|
| 1 | 面板高度固定，账号数量按 3–4 个画 | 账号 6 个以上时面板会超出屏幕；原型没定义滚动 | 面板最大高 560pt，超出后内容区滚动，头部与底部命令固定 |
| 2 | 只有鼠标悬停态 | 键盘用户无法操作；HIG 要求可聚焦 | 增加 Tab 焦点环（0.5pt 系统蓝描边）、⌘R 刷新、⌘N 添加、Esc 收起 |
| 3 | 时间轴只画了「有重置时间」的窗口 | 积分制账号（WorkBuddy）没有重置时间，放不进时间轴 | 时间轴只放有重置时间的窗口；积分单列一行（已在 MVP A 规格中定义） |
| 4 | 刷新只有静态「00:04 更新」 | 没有进行中状态，用户不知道点没点上 | 刷新时图标旋转 + 文字改「刷新中…」，旧数值保留不闪 |
| 5 | 菜单栏画的是「圆环 + 12%」的自绘图形 | `NSStatusItem` 的 template 图无法混色，深/浅菜单栏需要两套 | 用非 template 的自绘 NSImage（两种外观各一张）+ attributedTitle 承载数字 |
| 6 | 原型是静态多舞台，没有转场定义 | 两级切换若直接换视图会硬切 | 二级推入用 180ms 横向滑动 + 面板高度 180ms 动画；支持「减弱动态效果」时改为淡入 |
| 7 | 视图切换没有记忆 | 每次打开都回到默认视图 | 记住上次选择（UserDefaults） |
| 8 | 原型里的「剩余」写在副标题 | 真实数据有百分比与积分两种口径，副标题承载不下 | 头部写「剩余」，积分类在数值后直接给「1,579 / 13,326」，不再二次解释 |
